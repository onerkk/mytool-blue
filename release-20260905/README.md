## 提示詞深度如何改善

本次強調回答完整問題，綜合相互作用，而非堆砌術語或逐項複述資料；學理可補充，個案資料不能補造。八字保留格局、扶抑、調候等多角度；紫微保留實際三方四正、四化與運限；塔羅保留牌位、幾何、順序與 Book T 方法；其他系統分清不同流派與成立條件。

`seven-dimensions-system.txt` 是此次 Pages 備用端點的七維系統提示詞文本，方便核對及移植。它尚未寫入正式站外部 Worker。

這些修正可檢查資料忠實度與分析結構，不能據此宣稱占卜預測已獲科學驗證、命中率提升至某個百分比，或每個 AI 都會給出相同且正確的結論。

## 套用

將 ZIP 內容依原路徑覆蓋到專案根目錄後重新部署。務必一起包含 `index.html`、`JS/picker-core.js`、三個選擇器入口、`JS/sw.js` 及 `functions/api/pulse.js`。新舊選擇器不可只覆蓋一半。

Cloudflare Pages Functions 需透過支援 Functions 的部署流程發布。純靜態上傳不會自動產生後端；參見 [Cloudflare 官方路由說明](https://developers.cloudflare.com/pages/functions/routing/)。

統計讀取可沿用既有 `COUNTER_GAS_URL`；重設需在 Pages 伺服器設定 `COUNTER_ADMIN_TOKEN` 或 `ADMIN_TOKEN`，並與已登入管理員的 token 對應。不要把 token 寫進前端。一般統計讀取不需要管理員 token。

部署後先確認完整月份、年份選擇、時間／城市捲動及底部按鈕，再核對已知／未知出生時辰的複製內容。正式七維 Worker 與手機驗收完成前，請勿把這個版本標示為「全部根治、零 Bug」。
