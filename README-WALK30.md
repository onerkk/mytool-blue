## 嚴重既有 bug：合盤完全無法產生提示詞（已修）
- 現象：真實操作按「展開八字與紫微雙人合盤」，必定跳出「本次原題與必要資料共有 39949 字，超過單次貼上預算」，使用者永遠拿不到合盤提示詞。自 10/15 單次貼上架構上線即存在；既有測試夾具只有真實資料的五分之一，所以全綠。
- 根因：合盤寫入器是為八字合盤設計，紫微雙向資料（形狀不同）被同一個寫入器整包標為「必要」：兩人宮位星曜各 5,873 字、跨盤投射與逐條方向 18,993 字。
- 修法（JS/prompt-single-paste.js，同步到全部鏡像與後端）：紫微雙向改用專屬寫入器——每宮一行「宮名/地支/宮干/主星與煞曜（亮度、生年四化）」；宮位疊合一行一支；跨盤四化用已去重群組，題目主宮列必要、其他宮位選填；雜曜、飛化自化、格局來因、出生時間稽核、紫微運限改為選填。八字雙向的天干地支跨盤作用改為一行一筆表格，三合三會等組合選填，同步運限保留目前起三年為必要。
- 結果：真實資料 8,876 字、15,764 bytes；19 區塊納入，9 個選填區塊列入【未展開細表】收據。
- 防再犯：新增 tests/compat-real-ui-20261021.cjs＋tests/fixtures/compat-real-ui-20261021.json（真實介面擷取，330KB），已掛入 npm test。
