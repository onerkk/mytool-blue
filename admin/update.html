01連接你的網站

只傳送到 GitHub；此工具不儲存授權碼。可使用手機密碼管理員填入。

第一次使用？完成一次授權設定
  1. 開啟 GitHub 的授權碼設定，建立 fine-grained personal access token。
  2. Resource owner 選 onerkk；Repository access 選 Only select repositories → mytool-blue。
  3. Repository permissions 的 Contents 設為 Read and write，設定合適到期日後產生 token。
  4. 把 token 貼入上方。過期時重新產生即可；不需要把 token 傳給任何人。

本站已觀察到 master 提交後由 GitHub Pages 自動部署。此工具會查詢每次提交的部署結果。

進階：更新目標

變更目標後須重新檢查。受保護分支若要求 Pull Request，請依專案規則處理。
