# 靜月之光：提示詞與自動選陣修正

版本：20260910professional1。適用基底：本次上傳的 `mytool-blue-master.zip`。此包只含修改或新增的檔案，不是完整網站。

## 套用方式

1. 先保留現有網站備份。
2. 將本包解壓後的檔案，依原有相對路徑覆蓋到專案根目錄；不要刪掉沒有出現在本包裡的檔案。
3. `index.html` 的相關資源版本已更新，`JS/sw.js` 快取升為 v60。更新部署後重新載入網站。
4. 原專案依賴已安裝時，可執行 `npm test` 重跑測試。本次驗證直接執行各個本機 Node 測試檔，沒有下載套件或呼叫付費 AI。

## 自動選陣的代表性結果

| 問題 | 塔羅 | 雷諾曼 |
| --- | --- | --- |
| 他為什麼最近不主動找我了？我該先開口嗎？ | 關係牌陣 | 九宮格 |
| 她喜歡我還是只是禮貌？ | 關係牌陣；比較可能解釋 | 五張線；比較可能解釋 |
| 我應該留下還是離職？ | 二選一 | 雙路比較 |
| 要不要主動聯絡他？ | 二選一：採取／暫不採取 | 雙路比較：採取／暫不採取 |
| 我應該選 A 公司、B 公司還是創業？ | 凱爾特十字看共同局勢 | 九宮格看共同局勢 |
| 今年感情、工作、財運如何？ | 黃道十二宮 | 大牌陣 |
| 我想找回錢包，該從哪裡找起？ | 小阿卡那實務陣 | 依線讀整理脈絡，不保證位置 |

三個以上方案沒有每一方案獨立的結果牌，因此不產生虛構分支或成功排名。若使用者要逐路占卜，提示詞會請其確定兩個方案後另起一局；既有牌仍可分析共同處境。

## 方法與驗證範圍

- 方法來源及本站變體見 `research-sources.md`。本次有實際上網查閱，不把搜尋結果標題冒稱全文，也不稱流派存在唯一官方答案。
- 自動選陣是本機的問題結構與意圖規則，沒有接入新的付費 AI。56 個指定自然語言案例及其實際抽牌／匯出通過，不能據此宣稱所有自然語言都能百分之百判對；手動選陣、可見理由及資料限制保留給使用者判斷。
- 測試是程式與資料一致性檢查，包括 14 種塔羅／27 種牌陣讀牌組合、384 種梅花本卦動爻組合、60 首籤文保真及五種雷諾曼牌陣；不等於 AI 每次輸出皆遵循指令或占卜已驗證靈驗。
- 本次沒有呼叫付費占卜 API、修改付款／帳號／額度、操作賣場或發布網站。
- 原碼中的外部 `jy-ai-proxy.onerkk.workers.dev` Worker 原始碼未包含在附件。已修改的 `functions/api/ai.js` 是本地 Pages API；覆蓋本包不會更新另一個外部 Worker 的 system prompt。前端複製提示詞及資料封包修正則包含在本包。
- 既有運算表、詩文與牌圖未重製；此次重點是方法、選陣、資料傳遞與解讀提示詞，不宣稱重新驗證全站每一段歷史功能。
