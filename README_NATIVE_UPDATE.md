# 20261003native2 更新說明

這是既有 mytool-blue-master 的更新包，需合併到原專案；單獨打開更新包的 index.html 不會有原專案全部圖片和素材。

1. 解壓縮更新包。
2. 所有檔案與資料夾合併覆蓋到原專案根目錄，也就是原本 index.html 所在的那層。JS、CSS、data 等資料夾要合併，勿只選幾個檔案，也勿整個刪掉原資料夾。
3. 關閉網站再重新開啟。本版已更新程式網址與快取版本。

Android若出現「選擇開啟工具」，先存到下載資料夾，再從「我的檔案／Files」找到ZIP並解壓縮。使用備用 .zip.down 時先刪檔名最後的 .down，變成 .zip。不要選Google錢包、列印或文字編輯器開啟壓縮檔。

本版新增完整七曜六力、六壬64課族、人元司事與八格63條、五層流曜、西洋次限宮位、原圖81數及60籤逐首補充，已接入結果、提示詞與JSON。採用版本、來源、驗證及仍未涵蓋範圍見 docs/native-engine-implementation-20261003.md。

十五接口接入並通過列出的測試，不等於所有古籍門派與專盤皆完成。缺資料會明列，不補造時柱、盤位、排名或未做的占卜輪次。
