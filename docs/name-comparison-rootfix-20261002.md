# 姓名比較修正 · 20261002name2

本次修正「已在問題提供現名／原名，引擎卻只輸出候選，導致 AI 無法判斷是否比原名好」的完整資料流程。更新以 `mytool-blue-master(20261002-125839).zip` 為基底，保留原目錄結構。

## 修正內容

1. 問題明列「現名陳政軒」「原名：陳政軒」等資訊時，自動保留來源並實算基準。也可在專用欄填完整姓名；兩處不一致會提示統一，不能暗選其中一個。未提供姓名不讀帳號記憶補值。
2. 原名加入逐字筆畫／讀音覆核、結果詳細頁、比較表、完整提示詞和下載 JSON。支援單名對照原名，以及五個候選加一個基準。基準也在候選中時不重複計算。
3. 比較逐一保留改字、人格／地格／外格／總格、三才兩段作用、現代書寫成本、音形字義、生肖字根、八字用字與固定姓名卦。共同姓氏與不變格數不當成新增優勢。
4. 姓名專用語義以本次候選與明示基準綁定比較對象；「現名／現在名字」不當流年期限。「那個」在比較語境的讀法明列為暫定解讀，原問句不改寫。不再附入遺失比較關係的通用語義模型。
5. 主要與替代筆畫都保留完整五格、三才和姓名卦，另列人工覆核與字表原值。口徑差異不直接扣分；康熙數理總畫不混成現代書寫總畫。
6. 讀音候選、本人確認、字義資料、字根拆解範圍各自標示。未知現代筆畫不以 0 拼出完整書寫總數。補上本次比較用字的中文字義摘要與教育部來源。
7. 八字保留同一生辰原局；提供的實算出生瞬間不同時拒絕套用。姓名取象另列調候候選的已透／藏支／未見條件，不把「候選水」直接當還需補水或癸水用神。
8. 舊版姓名 JSON 若只缺原名，提示詞建構前會依同一設定補算；不再把補算工作推給讀者。提示詞共用一次原局並引用完整欄位，去除重複資料，保留各候選的全部必要事實。
9. 成稿須分別回答「候選內部首選」與「是否足以取代原名」。每個候選都交代較好／較差／相同／待核的面向、最強反證、改判條件與保留／調整的字。不按吉數投票、不把生肖喜根與忌根相抵、不以之卦一句否決姓名。

## 本次問題的資料驗證

原問句：`那個比現在名字好 現名陳政軒`。候選為弘林、鴻淋、沐洪、水扁。

| 姓名 | 本版康熙還原五格：天／人／地／外／總 | 本版三才 | 現代實際書寫總畫 |
| --- | --- | --- | --- |
| 陳政軒（基準） | 17／24／18／11／34 | 金火金 | 29 |
| 陳弘林 | 17／21／13／9／29 | 金木火 | 23 |
| 陳鴻淋 | 17／33／29／13／45 | 金火水 | 38 |
| 陳沐洪 | 17／24／18／11／34 | 金火金 | 26 |
| 陳水扁 | 17／20／13／10／29 | 金水火 | 23 |

「政」在所採 Unicode 14 康熙部首還原資料為 8，現代筆畫為 9；不是把現代 9 畫偷偷套進康熙主算。原名現代口徑另列 11／19／19／11／29。使用者明確覆核「政」為 9 時，康熙主算改為 17／25／19／11／35，並保留人工來源及原資料值。

陳政軒與陳沐洪的主算格數相同，不能以吉數多寡說後者一定更好；改字、字義讀音、書寫成本與兩套口徑仍分開比較。這些是計算事實，沒有預設最後要選哪個名字。

來源範圍：沿用專案內 Unicode 14／17 快照及既有卦文。另核對 [Unicode Unihan 說明](https://www.unicode.org/reports/tr38/)、[康熙字典攴部「政」](https://ctext.org/dictionary.pl?char=%E6%94%BF&if=gb)、[教育部「政」](https://dict.variants.moe.edu.tw/dictView.jsp?educode=A01720)、[「軒」](https://dict.variants.moe.edu.tw/dictView.jsp?ID=44309&la=0)、[「淋」](https://dict.variants.moe.edu.tw/dictView.jsp?ID=24038&powerMode=2&q=1)，及教育百科 [鴻](https://pedia.cloud.edu.tw/Entry/Detail?title=%E9%B4%BB)、[洪](https://pedia.cloud.edu.tw/Entry/Detail?title=%E6%B4%AA)、[水](https://pedia.cloud.edu.tw/Entry/Detail?title=%E6%B0%B4)、[扁](https://pedia.cloud.edu.tw/Entry/Detail?title=%E6%89%81)。新增中文說明是字義事實摘要，不冒稱完整字典引文或本人命名用意。
