# 姓名書房更新

本次以姓名學獨立流程補齊入口、可核計算、原生結果和完整解讀提示詞；原有各命理模組保留。完整判讀指引提升到9.1，同步各入口及內嵌備援，避免不同快取給出不同分析要求。

## 使用者可直接完成的流程

- 首頁第13個入口放在六爻／易經之後，手機跨兩欄、桌面跨整列；不留半格空位。
- 專用姓名書房：原生Three.js書卷、毛筆、硯台與姓名題字；低動態設定、WebGL失敗回退插畫，關閉時回收渲染資源。場景按需渲染，不持續消耗手機GPU。
- 填寫姓與名 → 逐字覆核筆畫及本人讀音 → 六個角度的原生分析 → 複製完整AI提示詞或下載本次JSON資料。
- 單名分析，或最多五個同姓候選名字，使用同一生辰及筆畫口徑比較；不平均各派吉凶成「命運總分」。
- 所有姓名與生辰由本頁明列。資料只留在本頁的當次操作，不讀帳號記憶、其他占卜或歷史姓名，不自動傳給外部AI。

## 筆畫與資料透明度

`JS/name-data.js`包含102,998個字，其中63,696個有Unicode 14.0.0 `kRSKangXi`部首＋餘筆畫的可追溯還原數。使用舊版本是因為Unicode在15.1已移除該欄；不是宣稱逐字核對康熙原書。

現代筆畫、部首與普通話資料使用Unicode 17.0.0：`kTotalStrokes`、可用的台灣alternate、`kRSUnicode`、`kMandarin`、`kXHC1983`及`kHanyuPinlu`。它們不是教育部逐字核對結果；界面提供教育部筆順網站，讓使用者核實現代字形。字義保留來源，英文釋義不冒充中文原文。

保留實際輸入的繁簡與異體字，不自動替換字形。數字「一」至「十」可選按字形或按數值特規。人工覆核保留來源，另一筆畫口徑的比較不沿用人工數。未知康熙數不以現代筆畫或碼位猜數；五格、三才、姓名卦暫留缺口，音義及生肖各自照常分析。

字形五行僅按本版明列取象表：木／艹／艸／竹，火／灬，土／山／石，金／釒／钅，水／氵／冫。玉、日、月等跨派分歧字根沒有硬配五行。音韻、字義、數理與字形五行不混成同一張表。

資料快照來源與SHA-256位於`data/name/sources.json`，Unicode及Three.js授權檔隨更新保留。傳統生肖與三才表來自本站既有明列表；81數理的建議為本次重新整理的白話提醒，沒有複製未核對的現代占斷文章。

## 部署與再現

ZIP保留原目錄結構，將內含檔案覆蓋至原專案同一路徑。新增字表及3D場景已生成，可直接用於既有靜態站，不需要在使用者瀏覽器安裝套件。入口、資料、提示詞與CSS皆使用`20261001name1`版本；Service Worker提升到v106。

```sh
npm ci
npm run build:name-scene
python scripts/build-name-data.py --unihan14 /path/Unihan-14.0.0.zip --unihan17 /path/Unihan-17.0.0.zip --check
npm run test:name
npm run test:recommendations
npm run test:comprehensive
npm run test:name:browser
```

重新生成字表使用上述兩個官方原始ZIP，腳本不主動連網。瀏覽器測試需要Playwright及Chromium；可以用`JY_CHROMIUM`指定執行檔。受限容器可加`JY_SINGLE_PROCESS=1`；每個尺寸使用獨立瀏覽器。瀏覽器測試攔截本機站點資源，阻擋外部API與Service Worker，不依賴登入或發送使用者資料。
