# 提示詞完整性修正（2026-10-10）

將本壓縮檔內的 `mytool-blue-master/` 同名檔案覆蓋至原專案；根目錄與 `JS/` 的副本都需要更新。此包只包含有變動或新增的檔案。

## 修正內容

- 全部 15 種方法都載入完整專屬判讀指南，保留原問題、原盤事實、支持與反向證據、成立條件及時間層級。依問題選擇回答範圍；沒有要求完整報告時，不強制解讀所有宮位或流年。
- 統一主頁、獨立入口、共用模組、內嵌副本與 API 的工作流程，補齊共用腳本缺少或舊快取混用時的完整指南。快取版本更新至 `jy-main-v122`。
- 分清命盤附帶資料與使用者要求的範圍。「前八個大限的所有流年」保留 80 年，避免誤展開成 120 年；指定年份、指定大限與單一問題各自保留範圍。
- 紫微資料保留星曜、宮位、自化、生年四化、飛宮來源與落點、流年干支及限流對應。生日增歲使用實際參照時點，全年跨大限時保留生日切換前後兩段。
- 原盤事實核對可辨認明確引用錯誤與漏列流年，並區分假設、借星與不同時間層級。大型舊版組合提示詞使用可完整還原的 JSON 共用資料，避免完整指南新增後超出既有字數限制。
