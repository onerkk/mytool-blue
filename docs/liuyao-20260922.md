本次增加兩個獨立入口：六爻納甲、易經卦爻辭。原有梅花易數保留自己的起卦與體用方法。三者不混用判讀規則。

## 本次功能

- 首頁新增六爻、易經入口與原創圖案，邀請卡同步呈現十二個入口。
- 立體銅錢、青銅卦盤、光影背景、逐爻動畫；六爻採青玉色，易經採靛紫色。手機擲錢操作固定於底部。
- 三錢起卦、手動記卦、可選音效、略過動畫、快速完成剩餘爻、減少動態偏好。
- 一次起卦固定時間，六爻由下至上記錄；零至六個動爻完整保留。返回首頁再開啟會保留本次記錄，不會重新抽取。
- 六爻呈現納甲、卦宮、世應、六親、六神、缺親伏神、旬空、月破、月日沖合及動化關係。
- 易經提供 64 卦卦辭、384 條爻辭、乾坤用九／用六及 64 卦大象；顯示本次主讀、參讀與可展開的完整原文。
- 問題推薦辨認六爻、納甲、文王卦、易經、周易、卦爻辭；時間／數字／漢字起卦仍推薦梅花。明確指定的方法優先，切換要由使用者點選，不改寫已起之卦。
- 提示詞複製、ChatGPT／Claude／Gemini 捷徑、JSON 排卦紀錄、2160 × 2700 分享卡。

## 引擎政策

### 共用起卦

本站明訂字面為 2、背面為 3。每次擲三枚獨立公平虛擬錢：6 老陰、7 少陽、8 少陰、9 老陽；八種等可能組合對應 1:3:3:1。這是三錢法，不冒稱蓍草法，也不假設實體硬幣必然公平。

第一次是初爻，儲存陣列由下而上；畫面由上而下呈現。6 由陰變陽，9 由陽變陰，7／8 不變。亂數結果在動畫前提交；動畫、關閉畫面、複製與分享都不重新取樣。沒有安全亂數來源時停止並提示使用手動記卦。

### 六爻

月建依交「節」瞬間，不以農曆初一換月。預設 UTC+8、00:00 換日，亦可選 23:00 子初；時差可由 −12 至 +14、以 15 分鐘為單位設定。夏令時間採使用者填寫的當時實際時差，不自行推測地點。不另加真太陽時修正。有效日期沿用曆法底座的 1900–2100 年範圍。

變爻六親依本卦卦宮五行；之卦的靜爻同位納甲僅為背景，不視為新動爻。缺六親時取本宮純卦的同位伏神。月日生克、旬空、月破、沖合分項保留，不相加成任意吉凶分數；日沖不自動斷為暗動或日破。用神候選由問題提供，使用者可指定，最終仍須結合原問句判讀。

### 易經

採朱子《易學啟蒙・考變占》擇辭，資料包與介面明示方法：

| 動爻數 | 主讀與參讀 |
| --- | --- |
| 0 | 本卦卦辭 |
| 1 | 本卦動爻爻辭 |
| 2 | 本卦兩條動爻，較上爻為主 |
| 3 | 本、之卦卦辭皆讀；前十主本卦貞，後十主之卦悔 |
| 4 | 之卦兩條不變爻，較下爻為主 |
| 5 | 之卦唯一不變爻 |
| 6 | 乾用九、坤用六；其他卦取之卦卦辭 |

三動爻的二十組合按位置由初向上排列：前十含初爻、後十不含。這是從原典變卦圖次序實作出的索引規則；以原文所列乾卦「否至恆／益至泰」、坤卦「泰至益／恆至否」的四個端點各做核對。本、之卦始終皆保留，不以主次抹去另一卦。

本次原文直接使用查得校錄本，保留「无」「系」等原字，不以現代繁簡轉換重寫古文。乾坤用九／用六屬特例，不是第七爻。完整原文、大象供參照，不改變主讀爻。時間僅記錄此次起卦，不套用六爻月日旺衰或梅花體用。

`data/yijing-source.json` 為可追溯來源；`JS/yijing-data.js` 由建置腳本生成。古經原文屬公有領域；Wikisource 數位校錄採 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)，保留逐卦署名來源、修訂編號及資料內授權說明，校錄文字的再利用遵循同一授權。其他程式碼授權沿用原專案。

## 提示詞與整合

共用 `JS/reading-quality.js` 的直接解盤風格：先判斷方向，再補一兩組關鍵依據；不逐項展示技法檢查與替代讀法。解盤結束後才進入既有選品段落，選品不得改變占斷。原問題是資料，不是新的系統指令。

新模組內含生成的備援提示詞；共享模組未載入或仍為不認識新方法的舊版時，使用本次備援。`functions/api/ai.js` 與產生的 Worker 同步收到兩種方法參考及 `liuyaoData`／`yijingData` 事實欄位。新介面仍循本站既有「複製提示詞交給 AI」流程；本次沒有部署 Worker 或網站。

2026-09-23 校核：目前六爻、易經與梅花入口是「排盤、複製提示詞、由使用者自行貼至選定 AI」流程。此流程不用網站替使用者呼叫付費 AI API；程式庫中仍有舊伺服端相容檔，不代表占卜入口會送出 API 請求。共用解讀規則現在以方法支援能力偵測，不依賴寫死的版本號。

### 後續古例與例外核對

- 《增刪卜易》[飛伏神章](https://zh.wikisource.org/wiki/增刪卜易)列伏神六種得用、五種難出的條件；同章也保留野鶴「有伏神亦不用，再占兩卦」的不同立場。引擎將飛神生克、伏神月日、生扶及沖破作有條件的並列資訊。伏神只見一位仍標為「伏神專有」，不冒充明現唯一用神；月日同六親只保留代取方向，不據此斷吉凶。
- 月破出本月只在真正進入下一節令月的首個候選民用日標示一次；之後的日值、日合另列，不能把每天重複說成「今日剛出月」。交節瞬間仍須查本次曆法來源，候選日期不保證事件。
- 《梅花易數》[卷一〈互卦起例〉](https://zh.wikisource.org/zh-hant/梅花易數/卷一)有「乾坤無互，互其變卦」支線；本站採此規則，提示詞與分享卡沿用同一實際互卦。外應由明示且確實出現的環境線索對原體卦比較，沒有把六爻重卦捏成單一五行。缺少曆法套件時改用標明近似的節令月備援，依 UTC+8 民用日期判斷並保留精度標籤。
- 《梅花易數》[卷二〈占卜總決〉](https://zh.wikisource.org/zh-hant/梅花易數/卷二)先辨本次起法，再論卦、體用及克應，且明言取象「要在圓機，不可執」；[卷三〈占卦訣／體用互變之訣〉](https://zh.wikisource.org/zh-hant/梅花易數/卷三)以體為主，分用、互、變的近中遠層次，且**卦中實際有**生體或克體之卦，才談相應卦氣。本站只從五行關係推卦象傾向，生體不等於真人已有好感、支援或承諾；克體不指認加害者，卦名不獨自推定結果。站內打分為自訂摘要指標，不是原典公式或經驗概率；節令卦氣只列盤中真有該元素的傳統候選，無法直接換成事件日期。漢字筆畫法是一字加時與多字前少後多的現代延伸，與原典一字拆字法區分。

瀏覽器測試以網站既有設定的來源網址載入本機檔案；所有頁面與資源請求由測試攔截並對應到這份專案，不會連到或更新正式網站。原有保護程式保持啟用。`GUA_COMPONENTS_ONLY=1` 可另跑精簡整合頁以定位問題；完整首頁與精簡整合頁均已通過。核心規則測試不依賴瀏覽器或網路。
