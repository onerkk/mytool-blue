# 靜月之光 · 2026-09-23 修正與驗證紀錄

這份更新針對原始網站的**純提示詞版**。使用者在本站起盤，本站組合帶入實際盤面的完整提示詞，使用者自行複製到選定的模型；網站本身不購買、不呼叫模型 API，也不把未取得的答案偽裝成現成解讀。

## 核對過的原始資料與明確邊界

- [《易學啟蒙》考變占](https://zh.wikisource.org/wiki/性理大全書_(四庫全書本)/卷17)、[《增刪卜易》及飛伏神章](https://zh.wikisource.org/wiki/增刪卜易)、[《梅花易數》卷一](https://zh.wikisource.org/zh-hant/梅花易數/卷一)用於逐條核對取用與互卦；完整對照記錄在 `docs/liuyao-20260922.md`。
- [S. L. MacGregor Mathers《The Tarot》1888 年第三法原文](https://sacred-texts.com/tarot/mathers/mtar04.htm)記錄了 66 張初排、11 張未發牌及另外兩張意外牌。後段重新疊組為大圓的句序存在歧義；本站沒有模擬這一段，**不能稱為完整復刻第三法**。
- [iztro 作者格局總覽](https://iztro.com/zh_TW/learn/pattern)用於紫微格局條件；[P. V. R. Narasimha Rao 原著印度占星教材](https://www.vedicastrologer.org/articles/vedic_astro_textbook.pdf)用於所新增的 Yoga 條件。曆法、星曆原始依據與各流派界線詳見 `docs/engine-rules-20260922.md`。
- 上述印度占星教材 34.2 節 Table 77 的傳統寶石表把祖母綠歸水星、紅寶石歸太陽；其他礦石不能只憑顏色替代同樣的原典處方。材質實物處理條件參見 [GIA 紫水晶照護](https://www.gia.edu/amethyst-care-cleaning)、[自然史博物館隕石分類](https://www.nhm.ac.uk/discover/types-of-meteorites.html)、[AAD 鎳接觸過敏說明](https://www.aad.org/public/diseases/eczema/insider/nickel-allergy)。
- [MDN Web Audio 技術文件](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)用於聲音解鎖和播放時序；`assets/audio/CREDITS.md` 逐段提供原始錄音與 CC0 出處。**來源沒有證明硬幣合金為銅**，因此只能稱真實硬幣錄音，不能宣稱古銅錢現場錄音；木筷、木杯墊同樣是實物擬音而非蓍草／筊杯原件。

`data/engine-rule-coverage.json` 列出各方法目前有條件的規則和未涵蓋流派。全量飛星／欽天、全部八字假從／救應、完整 Shadbala／Neechabhanga、所有 Jones 盤形、所有雷諾曼地方牌陣以及所有寺廟籤制不在已驗證範圍。新格局通過測試不等於能證實預測；第三人感情或同意仍須由當事人在現實確認。

舊 `computeJyotish` 曾公開於 `JS/bazi.js`，現行印度占星頁改走 `JS/vedic-engine.js`。保留舊函式以免破壞可能的既有嵌入，但不將它的舊宿命式文案視為現行原生引擎結論。某些歷史 v80/v101 測試硬編碼要求已被移除的冗長提示詞或舊版號；發行驗收使用當前方法事實與使用者操作的反例，不能藉恢復舊文案讓過時斷言變綠。

## 驗收與使用

本次 `npm test` 與 `npm run test:browser` 皆以結束碼 0 完成，逐項紀錄見 `docs/qa/npm-test-20260923.log`、`docs/qa/browser-test-20260923.log`。重跑指令：`npm test`；真瀏覽器：`JY_CHROMIUM=/path/to/chromium GUA_CHROMIUM=/path/to/chromium npm run test:browser`。測試涵蓋引擎反例、八種雙人合盤的事實與文字上限、提示詞版零 API 請求、分享卡、橫向溢出及窄螢幕操作。舊 API 整合回歸使用模擬上游，不會代表本站提示詞版須使用付費 API；瀏覽器模擬也不等於真實手機喇叭、銅錢材質或使用者自行選用模型的回答品質測試。

本包只含相對於使用者原始 `mytool-blue-master` 上傳檔實際新增／變更的檔案。解壓後依相同相對路徑覆蓋；不包含不變的原始專案檔案。兩份 Service Worker 和前端檔版本一併更新；仍需由網站擁有者部署到其主機。若另行修改前端共用提示詞，先跑 `npm run sync:recommendations`；3D 原始碼修改則先跑 `npm run build:gua-scene`。
