## 操作與部署

- 各儀式有音效開關，全站共用靜音與音量偏好。易經、六爻、靈籤的「⋯」可調音量與試聽。
- 首次操作解鎖瀏覽器音訊，不在首頁自動播放。減少動態與靜音各自獨立。
- 返回、略過、取消與分頁隱藏會停止目前及排程中的聲音。靈籤關閉、重置也會清除尚未完成的轉場。
- 下載或解碼失敗可以重試，不回退到合成音。手機仍受使用者媒體音量和瀏覽器播放政策影響。
- 將壓縮包依路徑覆蓋至專案根目錄，連同 assets/audio 新檔一起部署；入口檔與 Service Worker 版本已更新。
- 起卦與排盤引擎未改寫；動畫使用已提交結果，不重新抽卦。減少動態、取消演出或重開畫面不會改變已有的爻。

## 驗證

引擎與儀式：npm run test:gua、npm run test:yarrow、npm run test:ritual。

瀏覽器：GUA_CHROMIUM=/path/to/chromium node tests/foley-browser-20260922.cjs，以及 GUA_CHROMIUM=/path/to/chromium npm run test:gua:craft。前者以本地 MP3 檢查解碼、非靜音 PCM、輸出音訊圖、十二種方法的接點、偏好記憶、取消與錯誤重試；後者檢查十八變、行動尺寸、分享卡和 WebGL 降級。這些檢查不等於實體 iPhone／Android 揚聲器試聽。

技術依據：[MDN Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)、[Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[RoundedBoxGeometry](https://threejs.org/docs/pages/RoundedBoxGeometry.html)。
