# 十五種命理的同盤實答對照

每種方法各用一個合成情境，保留相同原題、當事人自述及固定盤面。每題分別將舊版和新版的完整匯出交給 Qwen3-1.7B Q4_K_M，得到三十則實際回答。基準版為 `8cbccec`，新版首答提示詞為 `fa4f769`。檢查回覆及補讀功能後續有更新，十五份首答提示詞均已逐位元組比對。

模型在本機執行。每次重新開始獨立對話，以種子 42、溫度 0.7、top-p 0.8、top-k 20 取樣，輸出上限為 1,600 個 token。兩版共用權重、取樣設定和輸出上限。提示詞的實際長度與停止原因逐案記錄。

## 固定判準看到了什麼

## 可以直接從原文重算的現象

| 可重算的指標 | 舊版 | 新版 |
| --- | ---: | ---: |
| 用盡輸出上限 | 10 | 3 |
| 至少有一行長文完全重複三次 | 12 | 3 |
| 行首印出「稱呼」或「開場」標籤 | 14 | 0 |
| 最後兩個非空行依序為指定連結及祝福 | 2 | 5 |

重複的判準為去除行首尾空白後，至少十二個字元的同一整行出現三次，略過 Markdown 引言和以反引號起頭的行。換句話說同樣的內容仍需讀者辨認。部分回覆用盡 token 上限，因此結尾可能中斷；原文照收。
