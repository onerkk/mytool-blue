# 手機牌圖與完整牌陣修正

本包接續前一份命理引擎修正包，只包含這次新增或修改的檔案。將 `mytool-blue-master/` 內的檔案覆蓋到既有專案的相同位置；新增的 CSS 檔也需一併放入。若從最初上傳的專案開始，先套用前一份引擎修正包，再套用本包。

修正內容：

- 七張線不再被原始 1,024 像素寬的圖片撐開；各種牌陣依螢幕寬高縮成完整總覽。
- 保留五張牌的 3＋2、雙路比較的共同背景、九宮格，以及 4×9 和 4×8＋4 大牌陣的牌序與幾何位置。大牌陣的手機版牌位編號顯示完整數字。
- 「全部揭開」顯示本次全部雷諾曼牌；逐張或自動翻牌完成後也進入相同總覽。
- 揭牌後的正面不再依靠多層 3D 背面隱藏。圖片載入中保留牌名，載入失敗會明示原因；靜態與完整動態都適用。
- 點選縮圖可查看完整單張，依牌序切換上一張／下一張，或使用左右方向鍵；關閉後保留原牌陣位置和焦點。
- 「展開完整牌陣」直接定位至牌陣區域。儀式內容可獨立捲動，操作按鈕保留在底部，短螢幕也能使用。
- 更新相關 JS、CSS 的快取網址與 Service Worker `v126`，避免繼續載入舊樣式。

驗證紀錄見同目錄的 `card-display-validation-20261014.json`。瀏覽器測試使用實際 Chromium 及專案的圖片、HTML、CSS 和 JS，包含手機、平板、桌面、短螢幕及橫向尺寸；屬於瀏覽器尺寸模擬，並非 Android 或 iPhone 實機認證。

可重跑的檢查：

```sh
npm run test:cards-layout:browser
npm run test:lenormand
npm run test:ui
npm run test:ritual
```

瀏覽器測試需要 Playwright 與 Chromium；可透過 `JY_CHROMIUM` 指定已有的 Chromium 執行檔。測試可用 `JY_UI_REPORT` 輸出 JSON 紀錄，`JY_UI_SCREENSHOT_DIR` 只供本機視覺檢查。截圖未納入本變更包。
