# 六爻／易經體驗修正 · 20260922gua2

此包只含相對上一版 gua 的新增與變更檔案，將內部相對路徑覆蓋到專案根目錄。無須安裝前端依賴即可部署，3D bundle 與音效已包含。尚未替使用者部署正式網站。

## 實際問題與修正

上一版的納甲引擎與周易擇辭引擎已分開，但輸入頁、三錢操作、CSS 銅錢與合成提示音共用，讓兩個入口的體驗過於相似。兩種傳統都能用三錢定陰陽，因此共用三錢並不等於卦象算法錯誤；問題是產品沒有清楚呈現各自的方法與體驗。

- 六爻預設三枚銅錢，六次成卦，維持《增刪卜易》納甲、六親、世應、月日與動變。
- 易經預設大衍蓍草，四十九策、每爻三變、共十八變，以《周易》卦爻辭和既有朱子擇辭方法解讀。另保留三錢與手動記卦；選三錢不會把周易判讀改成納甲。
- 蓍草每變都保存分策、掛一、左右餘數與剩餘策。完成三變才提交一爻；關閉、跳過動畫、快速完成、分享都沿用已記錄結果。
- 提示詞保持結論先行、像命理師當面解讀的共用風格；新增蓍草事實紀錄，不把它寫成銅錢紀錄。問題推薦加入蓍草、揲蓍、大衍筮法。
- WebGL 真實立體網格：銅錢方孔、倒角、厚邊、正背面、青銅盤與陰影；易經採蓍草、曲面古卷與書案。可拖曳觀察，手機使用有限像素比，離開畫面停止繪製，關閉釋放資源。WebGL 不可用／失效時保留靜態器物與全部起卦功能。
- 真硬幣錄音取代振盪器；銅錢著地時播放。預設靜音，由使用者啟用；載入失敗可重試，無聲也能起卦；關閉、略過與離開分頁會停止排程。
- 易經結果分享卡放主讀卦爻辭；六爻結果分享卡放月建、日辰、旬空、卦宮與六列納甲資訊。兩者分別呈現古卷與太極圖案、不同色系。
- 月光邀請卡改為三欄四列十二種系統，取自首頁同一份清單，完整包含六爻、易經。另附 `assets/share/invite-12.png`（2160 × 2700）並連接到頁面的直接下載入口。已儲存在手機的舊十種 PNG 不會自行變成新圖，請使用新輸出。
- JS/CSS 入口版本改為 `20260922gua2`，分享元件升至 4.0.0，Service Worker 快取升至 v93。

## 原典與取樣規則

[朱熹《易學啟蒙・明蓍策》，《性理大全書》卷十六](https://zh.wikisource.org/zh-hant/性理大全書_(四庫全書本)/卷16) 核對了：五十策取一不用；四十九策分二；每一變皆從右手掛一；左右各以四為組，整除時留四；第一變歸餘五或九，後兩變歸餘四或八；三變後剩餘策除四成六、七、八、九。

數位模型先等機率抽取左手的四種餘數，再從該類合法切點抽取一個切點。這對應原典的餘數分類，不是把所有物理切點視為等機率。64 條餘數路徑中，6、7、8、9 分別有 4、20、28、12 條，即 1:5:7:3；與三枚公平硬幣的 1:3:3:1 分開。使用 `crypto.getRandomValues` 和拒絕取樣避免模除偏差；無安全亂數時明確停止，請用手動記卦。

[《易學啟蒙・考變占》，卷十七](https://zh.wikisource.org/wiki/性理大全書_(四庫全書本)/卷17) 的擇辭規則沿用上一版，不因視覺、音效或起法改寫。古籍校錄是傳統方法來源，不是經驗上預測準確率的認證。

## 技術與聲音來源

- [Three.js MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)：金屬／粗糙度材質、環境光與貼圖。使用專案已宣告的 Three.js 0.186.0；bundle 保留 MIT 授權。
- [MDN AudioBufferSourceNode](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode)：讀取真實音訊緩衝區、排程播放與停止；不使用合成振盪器。
- [1_Coins.ogg，Jesús Lastra / jalastram](https://freesound.org/people/jalastram/sounds/223343/)：作者明示以電容麥克風錄製硬幣；該發布頁授權為 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。使用公開 HQ MP3／OGG 編碼，本地附檔；下載核對 2026-09-22。
- 原錄音未標明硬幣合金，不宣稱已驗證為特定古銅錢；它是真實金屬硬幣聲，並非電子提示音。完整署名、來源與播放處理見 `assets/audio/CREDITS.md`。
