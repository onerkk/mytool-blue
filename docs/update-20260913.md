## 提示詞改了什麼

| 系統 | 新版判讀重點 |
| --- | --- |
| 塔羅 | 牌義在實際牌位中做什麼；主導、阻力、轉折、落點如何承接。補強 14 種布局的組合主軸，正逆位與 GD 元素尊貴各依所選模式。 |
| 開鑰之法 | 計數路徑、原排列鄰牌、元素尊貴與配對分別形成作用，再依實際有效操作綜合；停止狀態原樣保留。 |
| 雷諾曼 | 補上 36 張牌的組合功能；相鄰片段逐步成句、長線重讀，再使用實際鏡像、宮位與騎士步。月亮的不同作者用法有明示。 |
| 八字／合盤 | 月令格局、根氣承擔、成敗救應、調候與取用先後；干支作用及歲運如何改變通路。合盤雙向十神與實際關係情境分清。 |
| 紫微 | 本宮星組、三方四正、四化來源與去向，以及本命／大限／流年疊宮共同形成結論。 |
| 梅花／靈籤 | 梅花由體用、旺衰、互變及取象說明過程；靈籤由完整原詩的語勢、條件、轉折和收束回應原問題。 |
| 西洋／吠陀占星 | 分清宮主、星體作用、相位與時間層；吠陀另分 D1、分盤及實際運期。只在相應資料存在時使用技法。 |
| 姓名／人格 | 先核對計算與模型來源，再解釋不同情境中的作用及比較取捨。 |

解讀知識由原有完整牌義／命盤資料與新版方法一起提供。本次沒有把所有可能牌組編成固定答案表，也沒有宣稱幾段指令能取代完整專業判讀。

## 引擎與資料修正

1. 八字重新整理十干 × 十二節令月的 120 個季節入口，保留候選天干、分工、條件與原文位置；五行集合由同一份天干資料產生。移除沒有所查古籍依據的 25% 顯示門檻及急迫度。季節參考與扶抑判斷分開，再由全局合參。
2. 紫微大限、流年、流月補齊十二宮地支映射；祿、權、科、忌每項都附本命宮與當期宮名，保留原星曜位置。
3. 綜合 AI 資料改用正確來因宮、參照農曆年及虛歲；補齊所有四化、宮干飛化、流月及大限資料。宮名按物件身分取得，序列旋轉不再錯配。
4. 本地 AI 備用接口補上獨立塔羅、開鑰等原始資料及方法資料包。十二類方法同時進入共用寫作層和本地 API；回應上限調為 8192 tokens。

時間與安星計算有跑既有獨立固定案例及邊界測試。沒有因為測試通過，就宣稱整套命理推斷的有效性已經被科學證明；亦未全面改寫原有五行權重、評分或曆法演算法。
