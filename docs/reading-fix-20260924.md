## 已修正的程式與資料問題

1. 八字跨盤補上含中神的半合及缺中神的拱合。案例中的酉丑半合金現在同時呈現在日支關係與跨盤事實；配對存在與成化判斷分開。
2. 刑的配對查找支援 A／B 對調，傳統方向另存。原本因人物排序而漏列的未戌等配對已補回。依《三命通會》卷二的本次採用口徑，統一寅巳申「無恩」、丑戌未「恃勢」；兩支相刑仍標示三刑未全。
3. 跨盤湊足三合／三會，明確記作兩盤分布；不再寫成任一人原局已成立的局。
4. 四化投射逐筆核對來源人、層級、天干、星曜、化象、受方與落宮。不一致就報錯。同干同星同化同落宮合併展示並保留所有來源，減少重複文字造成的假性加權。
5. 乙方甲干廉貞化祿與丙干廉貞化忌各自保留。沒有為了單一故事刪掉相反訊號。
6. 八字與紫微的問句運限範圍獨立使用各自年度基準。當前題使用當期，指定年份從已算資料選取，八字交運年度的兩段仍保留。原始 JSON 及完整序列化介面保留全部原資料。
7. 合盤提示詞不再展開大量未成立的格局字典與無關的終身大限；成立結構的支持、牽制、檢核條件仍保留。單人紫微也按問句選取運限。
8. 印度占星提示詞保留全部本命位置、分盤、運期與有效／取消／資料不足的格局檢核；未成立規則改列名稱與狀態，完整檢核仍在 JSON。去除純 JSON 縮排，降低複製內容量。
9. 共用指引、各入口的內嵌備援、根目錄鏡像與舊 API 文字副本同步；修正原有版本檢查，使快取中的舊指引不會覆蓋新版內容。公開頁面仍使用免費提示詞流程。
10. 修正快速開啟八字套件時城市資料尚未載入而留白的情況；載入後補上選項，保留已填資料。舊歷史提示詞標記版本，需要重新產生，避免直接複製舊解讀規則。
11. 首頁與相關延遲載入的版本標記更新，Service Worker 快取升至 v99。

未發現錯誤的排盤／抽取算法沒有為了製造變更而重寫；它們以既有的獨立參考資料與回歸案例核對。

## 驗證與使用

- `npm test` 中配置的回歸工作已分段執行；修正失敗項後重跑相關組。涵蓋排盤、抽取、方法選擇、原始資料到提示詞的一致性及既有介面。
- 既有參考包括：紫微 160 張凍結參考盤、八字曆法／換日／起運、100 組有方向的十神、印度及西洋各 167 組 Swiss／Moshier 星曆樣本、梅花 384 組、六爻／易經 4096 組、蓍草 64 條餘數路徑、塔羅與雷諾曼實際牌陣及 60 首原籤詩。
- 新增 `npm run test:reading-grounding`：這對命盤的四柱時辰、144 組地支雙向配對、四化來源與錯誤攔截、當前／遠期範圍、完整原資料保留、14 方法的判讀主線、舊指引備援。
- 新增 `npm run test:reading:browser`：實際頁面的案例表單、產生提示詞、複製、下載與原局不變。可用 `JY_CHROMIUM` 指向本機 Chromium。
- 瀏覽器檢查另覆蓋印度／西洋入口的複製與 JSON 下載，以及舊付費登入資料不會啟動付費 AI。原有免費瀏覽次數 API 在測試中以本地回應模擬，不對外增加瀏覽次數。
- 修改共用文案後執行 `npm run sync:recommendations`；用 `node scripts/sync-recommendation-guides.cjs --check` 確認各備援及鏡像同步。

測試驗證的是指定口徑下的計算、資料歸屬與輸出流程；沒有付費呼叫外部 AI，也沒有把提示詞測試寫成所有外部模型必然遵循、命理預測已被證實，或導購收入已有保證。下列範例另列於 `reading-example-20260924.md`，作為人工口吻與論證驗收參考，不是網站硬編碼答案。
