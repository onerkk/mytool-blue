## 文獻核對

R15 直接重讀 iztro 設定與作者規則，並檢查獨立安裝的 `iztro@2.6.1` 原始程式；MIT 授權隨包提供。160組參考盤由上游套件獨立生成，不以本地引擎產生預期結果。晚子時完整日期前推、預設午夜／不拆閏月等本站覆寫已明列，未聲稱與上游所有邊界相同。

R15 也重新開啟全部60首已選廟方籤頁，逐行比對四句原詩。第五籤沿用香山官方校正版；此核對不把故事、各事項或其他廟的版字當成同一版本。

## 驗證與使用

104支獨立Node測試最終全數通過；新增22,630項斷言、160組獨立iztro參考盤、60首原詩覆核，15引擎真實操作於390／1280像素通過（含姓名兩種模式，共32個入口情境）。最後修改另重跑15支受影響測試，再驗合盤與原生資料。合盤舊格式實測149808字元，低於原有150,000上限。最終結果、各測試時間、瀏覽器實際輸入／下載／複製紀錄、獨立參照與檔案雜湊見 `engine-validation-20261004-r15.json`；新增邊界斷言見 `ziwei-config-validation-r15-20261004.json`，全部原詩重讀見 `oracle-web-recheck-r15-20261004.json`。

解壓至原專案根目錄，覆蓋相同路徑。`CHANGED_FILES_R15.txt` 列出每個交付檔案與SHA-256；根目錄與JS鏡像同步，HTML／延遲載入的快取版本一起更新。新增測試入口為 `npm run test:r15` 與 `npm run test:r15:browser`。

「已補齊」指本專案上述15個引擎所選公開規格的已確認缺項與資料路徑。不存在跨所有歷史流派的统一官方總規格；私人師承、未量化原典條件與沒有輸入的觀察資料不能編造成已算證據。測試與文獻一致性也不等於預測效度或絕對零錯誤。此次保留這些界線，同時把可執行且有來源的確認缺項補成實際功能。
