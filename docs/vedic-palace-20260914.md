# 九曜星殿製作與核對

日期：2026-09-14。基準為前次印度占星工作區版本 `20260914sanctum1`；本次資源版本為 `20260914palace1`。

## 設計依據

比對網站既有的 `ritual-ateliers`、`cinematic-src/scenery.mjs`、`cinematic-src/choreography.mjs` 與 `cinematic-src/craft.mjs`，保留其立體物件、前景遮擋、鏡頭移動和工藝材質的做法。印度占星使用獨立的場景與四段編排；雕刻門扉及細部曲面共用網站既有工藝幾何工具。

| 目標 | 本次實作 |
| --- | --- |
| 能看出前後距離 | 全螢幕透視鏡頭，前景雙門、兩層立柱、底座、星環及後景 |
| 物件有厚度 | 擠出宮位片、厚邊框、三軸星環、曲面蓮瓣與多層底座 |
| 金屬與琺瑯有不同反光 | 環境光照、物理材質、表面粗糙度、鍍層及雕花金屬條 |
| 演出有推進 | 入殿、喚星、軌跡、命盤四段，最後開啟結果 |
| 顯示實際命盤 | 九曜經度與宮位由既有 chart 傳入；同宮標記排列使用原生 house |
| 手機也能閱讀與操作 | 四頁籤、黏性導覽、窄螢幕格線、觸控轉動及可取消的對話框 |

## 本次實際查閱的官方技術資料

- [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)：透視投影、長寬比與視角。用於手機和桌面不同畫面比例下的鏡頭構圖。
- [Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)：金屬、粗糙度、透明鍍層與環境貼圖。材質效果有額外運算成本，因此場景沒有堆疊全螢幕後製。
- [Three.js Reflector](https://threejs.org/docs/pages/Reflector.html)：平面反射、反射貼圖尺寸、裁切偏移與資源釋放。場景採用 512px 地面反射貼圖，離開演出時釋放。

以上來源支持圖形實作方式；占星計算沿用已記錄的原生引擎與前次方法文件。裝飾星環、動畫中間路徑與鏡頭不作天文運行資料使用。

## 資料與流程

- 原始 `chart` 由現有引擎完成後傳入演出。演出資料轉接函式保留各曜原生經度、星座及宮位，沒有重算時間或排盤。
- 北印度式十二宮片與結果圖使用相同宮位拓撲。出生時間未知時，演出保留九曜標記，結果頁不建立未定的上升與確切運期。
- 四段動畫使用同一個進度值。時間進度結束才啟用展開按鍵；略過和取消可隨時使用。靜態模式直接顯示完成構圖。
- 「重遊星殿」再次使用已有 chart。拖曳、切換頁籤、南北盤及分盤，不改寫原始排盤資料。
- 材質在正式計時前預先編譯；不變的雕花幾何按材質合併。背景分頁暫停演出，離開時移除監聽器、反射貼圖和渲染器。

## 實際驗證與界限

1. `tests/vedic-engine-20260913.cjs`：14 組數值及方法核對，涵蓋 167 組獨立 Swiss/Moshier 參考、極區及 Raman 案例、月宿分界、十六分盤、IANA 時區、大運切分及八分點表。
2. `tests/vedic-design-20260914.cjs`：13 組核對，涵蓋日期／時間、燃燒條件、月木格局條件、速度、時間誤差傳播、次副運、場景資料轉接與提示詞。
3. `tests/vedic-palace-20260914.cjs`：鏡頭穿門順序、連續性、十二宮落定、拖曳邊界、瀏覽器束檔、CSS 和載入版本。
4. 既有瀏覽器流程在 390×844、320×740、1440×1000 尺寸核對；包含實際觸控事件、上下滑動、全部十六分盤、九個副運、複製、取消、靜態、WebGL 中斷和未知出生時間。
5. 專屬場景錄製流程另外檢查左右拖曳、側面鏡頭、三組星環、十二宮片、地面反射及重播前後 chart 完全一致。

數值核對指選定計算方法與參考實作的一致性，不代表已證實占星預測能力。瀏覽器核對是桌面 Chromium 的裝置尺寸模擬；錄製環境採軟體圖形渲染，不能據此保證實體手機幀率。

全站舊有三張分享圖 `share-bg-tarot.png`、`share-bg-ootk.png`、`share-bg-general.png` 的缺檔仍在既有首頁請求中出現；本次印度占星新增場景素材未列入缺檔。
