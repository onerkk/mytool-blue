# 雷諾曼五張線：人工口吻與論證參考

這是本次依使用者問題及實際五張牌撰寫的人工參考答案，不是外部 AI 的實測結果，也不作所有相似問題的固定回覆。

原問題：我現任有躁鬱症 近期不穩定 我該如何幫助

牌序：鑰匙 → 鳥 → 騎士 → 雲 → 紳士；紳士為問卜者。

---

你現在可以先陪伴侶聯絡原本的精神科團隊，把近期變化整理清楚，再商量你能提供哪一種協助。既然你提到近期不穩定，就值得及早聯絡，不必等固定聊天或相處調整失敗。病情與治療由專業人員評估；這組牌能用來反思你如何參與照顧。

這次較有用的方向，是把焦急的談話轉成清楚的聯絡與行動。鑰匙接鳥，可取重要談話與找出入口；鳥再接中心騎士，重點進一步落在傳遞消息、取得回應。你可以問：「最近最難受的是什麼？你願意讓我陪你聯絡醫師，把睡眠和最近的變化說清楚嗎？」這是依原問題提出的做法，醫師並不是這副牌已指定的人物。

你也要為資訊不清楚保留餘地。騎士後接雲，雲又在你的代表牌紳士旁，較適合讀成消息進來後，你仍可能難以掌握狀況；不能據此斷言伴侶快速發作或你們已經越聊越亂。鑰匙帶來找入口的方向，但雲使「已找到完整解法」還不能成立，所以先確認具體變化，比自己補上原因更有用。

若伴侶願意，協助記錄最近睡眠、是否依原醫囑服藥，以及和平常不同的行為，帶給治療團隊參考；不要自行改藥。若疑似躁期、嚴重憂鬱或有即時傷害危險，應立即尋求專業協助。這些做法依 NIMH 與 NICE 的照顧指引，不能當成牌面提供的醫療判斷。

你的支持也需要能持續：商量你能陪診或聯絡的時段，並在取得同意後找其他可信任的人分擔。可以觀察的是是否聯絡上治療團隊、重要變化是否記錄清楚，以及雙方是否知道需要協助時找誰；這些進展不等於病情已經穩定。
