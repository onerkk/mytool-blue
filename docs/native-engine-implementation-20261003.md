## 文獻核對與版本差異

- 印度參考 P. V. R. Narasimha Rao 教材、BPHS 第 27 章與 Raman《Graha and Bhava Balas》。Raman 七分盤比例與 BPHS 不混為同一表；D1 的本質強位按實際度數，分盤不虛構細度。十度分組按 Raman 及梵文原典同一順序；部分英譯次序不一致已列明。月相採本模組明列 BPHS 口徑，沒有藉部分結果拼成六力總分。

## 提示詞與下載

每段新增資料標明方法、已計算範圍、來源及缺項；AI 不得自行补造未算部分。`$ref` 是同一 JSON 段內的完整記錄參照；所有指標已驗證可解析，結果頁的 JSON 下載仍是完整原物件。

雙系統合盤會按原問題期間補入新增作用，已在正文列出的原局、模型及跨盤事實不重貼。測試案例由約 34 萬字元重複資料縮至約 6.2 萬字元；完整 JSON 仍保留全部已算物件。要求全部大運／逐年時保留所問已算資料，不能把一般三年題擴成全人生，也不能承諾所有題型的完整資料都很短。

時辰未知的八字下載只有三柱與部分分析。印度、西洋與紫微依自身時辰政策排除不能確定的宮位、運期與作用，不把暫定參考時刻當作已确认時刻。
