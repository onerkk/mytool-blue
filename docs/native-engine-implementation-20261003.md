## 提示詞及缺資料

先計算原盤作用，再將同一資料傳給提示詞。完整JSON保留已算物件；提示詞按原問年份與範圍補入資料。$ref指向同段首次完整記錄，全部參照已驗證可解析。雙系統合盤樣例约12.3萬字元，較前版增加完整八格與流曜，不為縮短而刪除新增條件。

未知時辰的八字只匯出三柱，排除暫時柱格局旺衰與精確起運結論。印度、西洋、紫微按各自政策保留時刻敏感度與排除未確定宮位運期。null、未操作、資料不足與不成立分別記錄。
