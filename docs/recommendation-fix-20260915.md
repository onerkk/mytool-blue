# 選品依據與重複推薦修正 · 2026-09-15

本更新包包含前一版的開鑰之法修正，以及本次推薦規則 4.2.0。依原路徑覆蓋專案根目錄後，按原方式發布。沒有要刪除的檔案，不含 node_modules。

## 確認到的問題

上一版有要求依問題、盤面和佩戴條件選品，但不能因此宣稱每次 AI 回覆都已通過個別選材驗證。

- 共用材質範例把紫水晶放在最前面，並附上「沉澱／整理思緒」這類適用面很廣的象徵理由。各匯出入口又共用這一段，形成偏向同一答案的可能來源。本次未取得使用者逐筆測試的完整提示詞及 AI 回覆，不能把此推論稱為每次重複的唯一已證實原因。
- 水晶可以用假設的色彩偏好入選，龍宮舍利卻偏重於已確認的信仰偏好，兩類的選擇條件不對等，容易讓後者即使適合也被排除。
- 各入口只檢查共用指引是否具有某個方法；舊 4.1 版同樣具有該方法，因此新版入口仍可能讀到舊規則。本次以保留完整方法的舊版測試物件重現並驗證修正。
- 舊商品資料表與評分函式仍存在於歷史程式中；本次使用的複製提示詞沒有附上這些庫存排名。沒有把搜尋到的每一處歷史紫水晶字串都誤判為當前推薦來源。

## 新版要求

1. 推薦依據須能回到本次佩戴者的實際資料：具體牌位／牌組、柱位與取用、宮主與相位、有效歲運，或確實影響佩戴的已知條件。只有塔羅時，不冒稱已讀命主八字；不引用其他人的殘留資料。
2. 水晶、天鐵、龍宮舍利都可進入比較，沒有固定順位。先確定需要，再比較最相關的兩個候選，正文用一句說明主選比替代項更貼合哪個條件。
3. 移除共用指引中紫水晶的正面範例及其專屬參考連結，不禁止有依據的紫水晶推薦。使用者原問題明確提到紫水晶時，該問題仍原樣保留。
4. 「安定心情、整理思緒」不足以單獨指定某種礦物。若換掉品名後整段理由仍通用，應重新選擇或降低具體程度；資料不足時用已有飾品或受支持的品類方向，不編偏好硬選石種。
5. 天鐵及龍宮舍利也可按已知外觀、收藏用途或認同的文化意義比較。採信仰理由才需要相應信仰認同；未知的成分、產地、鑑別或宗教來源不能自行填補。傳統取象、物性與個人偏好分開說明。
6. 同一有效依據可再次推薦同一材質；改問不同問題、換命主或運期時須重新核對。沒有加入隨機輪替、配額或「每次必須換一種」的規則。

選品仍融入最後的行動建議，通常三至五句，承接賣場邀請；不把內部規則或比較清單原樣當作正文。

## 程式與驗證

- 共用規則、各獨立備援、前端 API 指引與提供的 Pages 備用端點同步為 4.2.0。同步腳本會一併維護版本檢查，避免下次只更新文字。
- 共用腳本版本不一致時，各入口採用自身的新版備援；主頁及動態載入版本為 `20260915rec2`，Service Worker 快取為 `jy-main-v86`。
- `npm run test:recommendations` 通過：16 組既有盤面／匯出測試，加上 11 組推薦測試。包含主要系統、全部籤詩、舊 3.x／4.0／4.1 指引、已知偏好保留、跨人資料不混用及沒有附入舊商品排名。
- `node tests/ootk-flow-20260915.cjs` 通過 7 組，含 512 次牌局、五次操作、完整播放、略過、回呼失敗及取消清理。
- 修改的 JavaScript 均通過語法檢查；本次沒有修改排盤或抽牌計算。

以上驗證的是程式、提示詞和實際匯出的資料，沒有捏造外部 AI 的推薦回覆，也沒有建立能保證外部模型遵循的語意驗證器。本次未呼叫外部模型或部署網站；未提供原始碼的外部 Worker 系統指令不在本更新包可修改範圍。

發布後重新複製提示詞，搜尋「規則版本 4.2.0」可辨認本次新版；先前已複製到其他 AI 對話的舊提示詞不會自動變更。
