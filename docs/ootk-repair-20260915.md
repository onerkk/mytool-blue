# 開鑰之法更新 · 2026-09-15

將更新包內的檔案依原路徑覆蓋到專案根目錄，再依原方式發布。這是變更檔更新包，不含整個專案或 node_modules；沒有需要刪除的檔案。

## 修正原因與來源

舊版把預選元素、宮位、星座逐關比對，任何一關未命中就停止，並不產生後續操作。畫面上的停止首先來自這個程序判定；另有資訊提示卡中斷自動播放及視覺回呼失敗後無法推進的問題。

實際核閱的金色黎明原稿與修訂版具有以下差異，不能混成一套「唯一正統」規則：

| 項目 | 金色黎明 Tarot Divination 原稿 | Liber LXXVIII 修訂版 |
|---|---|---|
| 牌堆選擇 | 找出代表牌所在堆並閱讀 | 另有驗題與停止要求 |
| Ace 計數 | 5，包含起算牌 | 11，包含起算牌 |
| 一般配對 | 首尾向內，包含代表牌；奇數留下中央單張 | 由代表牌左右兩側向外 |
| 第四操作起點 | 第一張環牌，沿發牌方向 | 沿前述方法；本網站明示以代表牌起算 |
| 第五操作 | 閱讀代表牌所在生命樹牌堆 | 預期位置未命中不必然失效 |

來源：金色黎明原稿〈The Opening of the Key〉及五次操作，見 [Tarot Divination 原稿轉錄](https://arcane-archive.org/tarot/tarot-divination-1.php)；可比對 [Golden Dawn Manuscripts](https://www.tarrdaniel.com/documents/Thelemagick/gd/publication/english/golden_dawn_manuscripts.html)。修訂版的停止、計數及各操作見 [Liber LXXVIII](https://sacred-texts.com/oto/lib78.htm)。核閱日期為 2026-09-15。

## 本次行為

- 預設「金色黎明原稿・完整五次操作」。只需選代表牌、確認方向；每輪獨立洗牌一次，原問題及隨機結果不因領域分類改變。
- 五輪依序保留四元素牌堆、十二宮、十二星座、三十六牌環、生命之樹；採原稿的 Ace=5、首尾配對及環牌起算。四堆翻面初示牌也交給解讀。
- 「Liber LXXVIII 驗題版」是可選版本，保留舊版停止檢核。第一輪預選領域及第三輪單一星座門檻是本站數位政策；它們不能移植成原稿版的停止條件。通過程式檢核也不等於問卜者確認主要線索。
- 預設連續演出；資訊附註不會鎖住前進。每層演出異常或超過 45 秒會結束該層視覺並保留已算資料；晚到的回呼失效。略過只略過演出，取消則退出流程。
- 飛牌使用該輪真實洗牌順序；十二星座按牌序輪發，四元素從右至左呈現。畫面、資料與匯出提示詞使用同一牌局。
- 選品自然承接原問題及前文具體牌組／命盤依據，說明主推薦與使用方式；水晶、天鐵、龍宮舍利均可依適配理由入選。各入口及獨立備援提示詞同步，不虛構商品規格、庫存或功效。
- 更新主頁、動態載入提示詞與 Service Worker 版本，讓既有瀏覽器取得新版。

數位約定：切牌取近中點的隨機邊界；原稿未規定偏移數字。原始卡圖沿用網站牌組，人物朝向不明時由使用者先約定方向。第三操作星座名屬牌堆位置；第四操作的十分度象徵不直接換算日期。程序完整不等於預測已被驗證。
