## 本輪實際修正

1. **蓍草操作看不到器物、也聽不到聲音。** 原先音效由 3D 畫面更新觸發；器物捲出視窗，GPU 停畫後連聲音也沒有。現在由獨立時間表播放實錄音效，按下操作後把器物帶回可見區。取消、略過、離開頁面會清除排程，背景不重播。
2. **三變進度提前跳到下一變。** 現在顯示正在操作的那一變及入案策數，歸餘階段才顯示本變剩餘數。內部既定的起卦資料不重抽，完成／略過／重開都沿用同一份紀錄。三錢同樣在落定後揭示正背結果。
3. **手機視覺與 3D 生命週期。** 收緊操作區、把六爻進度改為緊湊排列，讓器物、階段與主按鈕同時容易找到。調整金屬色、燈光及表面細紋；重接場景解除暫停，關閉器物及印度星殿時主動釋放 WebGL context。低動態模式與音效開關分開控制。
4. **單題被推薦成多選項牌陣。** 例如「這件事為什麼卡住？」沒有多個方案，卻可能被選成多選項。現在先檢查分支是否成立，再評分選陣。三個以上真實選項仍各自綁定位置；不再附上「沒有獨立結果牌」的矛盾舊提示。
5. **印度占星被泛稱「占星」蓋過。** 明確指定印度／吠陀、西洋占星現在分開辨識；排除的系統也不再被預設推薦選回。推薦按鈕可保留問句切換，關閉原占星頁並復原輸入焦點與頁面互動。
6. **雷諾曼分線名稱及限制不一致。** 提示詞標頭現在使用實際路數；真的已有多方案分線時，不再說這個版式沒有獨立支線。畫面、已抽牌數與提示詞仍依抽牌前的同一計畫。
7. **合盤提示詞被重複資料塞滿。** 合併重複的來源、範圍與格局核對內容，保留每條規則 ID、成立狀態、核對條件、證據、異說及四化落點。完整 JSON 不刪減。固定參照合盤由 113,654 字元降至 64,934 字元；八個情境為 64,917～64,938。這是測試案例數值，不是所有命盤的固定長度。
8. **紫微格局漏分支。** 補入君臣慶會的紫破輔弼夾命、紫相昌曲命遷兩種起例及煞忌否決；金輿扶駕採有標記的天府修訂說；陽梁昌祿要求四曜齊備，化祿不代替祿存；梁馬依真正同宮定位。每項有正例與排除例，不把命中名稱等同吉凶或現實事件。

各方法沿用統一的直接解盤文風：先回答，再給影響答案的關鍵依據；不逐項朗讀檢核過程，選品內容在解讀之後。規則資料精簡不等於省略解讀事實。

## 覆蓋與重跑

將 ZIP 依原路徑覆蓋。前端、提示詞來源、API／Worker、編譯好的場景及 Service Worker 應一起更新；不要只更新單一畫面檔。`CHANGE-MANIFEST-20260922-rules.json` 列明每個變動檔案與 SHA-256。

```sh
npm test
# 已安裝 Playwright 與 Chromium 時；也可用 GUA_CHROMIUM 指定卦象測試的瀏覽器。
JY_CHROMIUM=/path/to/chromium npm run test:browser
```

既有編譯結果已包含在包內。若另外更改 3D 原始碼，請執行 `npm run build:gua-scene` 或 `npm run build:vedic-scene`；若更改共同解讀來源，執行 `npm run sync:recommendations`。
