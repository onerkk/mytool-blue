# 分享卡預覽修正 · v3.0.1

本包接續 `mytool-blue-master-card-redesign-20260911.zip`，只包含這次預覽修正的變更檔。

## 問題與原因

已在 `https://jingyue.uk/` 點選「製作月光邀請卡」重現：PNG 已完成，下載按鈕可用，但預覽仍顯示「正在製作你的卡片…」。

正式站的預覽 `<img>` 同時具有 `hidden=true`、`display:none`、`loading=lazy`、`complete=false`、`naturalWidth=0`，而且已經有 Blob 圖片網址。`JS/ui.js` 的動態圖片觀察器會替未指定載入策略的圖片加上 `loading="lazy"`；分享卡則等圖片 `load` 事件後才解除隱藏，造成互相等待。下載使用已產生的 Blob，所以不受這個顯示問題影響。

瀏覽器載入策略參考：[MDN：HTMLImageElement.loading](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/loading)。修正以正式站 DOM 與專案原碼的交叉確認為依據。

## 修改內容

- 分享卡圖片在插入畫面前明確指定 `loading="eager"`，讓隱藏中的預覽也立即載入；套用於全部十種分享卡。
- 分開顯示製作中、圖片已完成但預覽載入中、預覽完成、製作失敗等狀態。
- 預覽出錯或超過 12 秒沒有完成，顯示可理解的提示，保留已成功製作的高清圖片供分享與下載；逾時後圖片若成功載入，仍可恢復顯示。
- 切換個資顯示時立即移除舊預覽，使用獨立圖片節點，阻止較早請求的成功或失敗回呼覆蓋新卡片。
- 關閉或重製時清除圖片網址、事件處理與預覽計時器；製作失敗時保持下載按鈕停用。
- 分享卡引擎更新至 `3.0.1`，入口網址更新至 `20260911preview1`，Service Worker 快取更新至 `jy-main-v62`。

## 套用

解壓後，依原本的相對路徑覆蓋到專案根目錄，再依既有方式重新部署。下列四個檔案是網站運作所需的更新：

| 檔案 | 用途 |
| --- | --- |
| `JS/share-card.js` | 修正所有分享卡的預覽載入及狀態管理 |
| `index.html` | 主站引用新版分享卡程式 |
| `preview-share.html` | 卡片展示頁引用新版程式 |
| `JS/sw.js` | 更新網站快取版本 |

其餘 `package.json`、`tests/` 與本資料夾提供測試及變更紀錄。原有素材與樣式沿用上一包，因此本包不重複附上。

部署後重新整理網頁，再點「製作月光邀請卡」；正常情況應顯示完整卡片，完成後不再留下製作中的提示。主站載入的程式網址應為 `JS/share-card.js?v=20260911preview1`。
