# 靜月之光：方法、資料與提示詞修正包

本包以本次提供的 `mytool-blue-master.zip` 為唯一比較基準，只包含內容有變更的檔案及本次新增的測試、查核記錄。沒有混入先前修補包，也沒有重新打包圖片、字型或 node_modules。

## 套用

1. 備份目前網站。
2. 將 ZIP 內的 `JS/`、`functions/`、`tests/`、`index.html`、`package.json`、根目錄 `meihua-standalone.js` 等路徑覆蓋到原專案根目錄；不要額外套一層資料夾。
3. 用原有方式發布靜態檔案。入口腳本版本已更新為 `20260908audit1`，Service Worker 快取版本為 `jy-main-v59`。
4. 在原專案執行 `npm test` 可重跑本包的回歸驗證。本次沒有更新依賴版本。

本次沒有執行線上發布、付費 AI 請求、訊息發送或帳號設定變更。

## Mathers 第一法的明示選擇

1888 原文列出 A26、B52；再分 C17、D35；最後 E11、F24。但最後35張若完全照「第2、5、8……張入E」讀到末張，第35張仍會入E，得到12／23，與書中列出的11／24不一致。

本站保留已公開的54張布局，採原文明列的組數：只從完整三張組中選取，末段不足三張的牌留在F。每張發入牌覆在堆頂；下一輪由該堆頂取牌；展開A、C、E時也由堆頂向左排列。這是有記錄的程式採法，不稱唯一無歧義的原典復刻。

- 不完整／重複／非法牌、混合讀法、程序失敗、空 OOTK 與中止後操作排除。

- 雷諾曼5種布局與資料失敗；60籤的詩文／號碼／匯出完整性。
- 既有日期與時辰選擇器、鍵盤視窗與焦點還原、抽牌及開鑰按鈕、腳本載入失敗、API失敗、背景繪圖生命週期回歸。

新增方法測試亦在 Asia/Taipei 與 America/New_York 時區重跑通過，核對節氣瞬間不隨主機時區錯位。

完整測試輸出見 `test-results.txt`，封裝清單與 SHA-256 見 `manifest.json`。

這些驗證涵蓋程式執行、資料契約與模擬 DOM 事件。未使用真實手機／瀏覽器做像素驗收，未呼叫外部 AI 對解讀品質打分，也未建立預測命中率研究。60籤測試驗證資料完整性，不表示全部詩文與典故都已逐筆獲各廟認證。網路查核的實際來源及權限見 `research-sources.md`。

## 外部 Worker 的適用範圍

主站 `JS/ai-analysis.js` 仍指向既有 `jy-ai-proxy.onerkk.workers.dev`。附件沒有該 Worker 的完整原始碼或部署配置。因此，本包的 `functions/api/ai.js` 是 Pages 備用端點的修正，不會自動更新外部 Worker 的 system prompt。

若目前營運使用外部 Worker，需由維護者將本包 API 範本中的方法契約同步到該服務，並依原有部署程序驗證。前端各獨立工具的提示詞匯出修正，直接由本包靜態檔案提供。
