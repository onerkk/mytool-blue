# 靜月之光 · Celestial Atelier 整合更新

版本：20260911celestial1。這份壓縮檔包含前兩版介面修改與本次強化，可一次覆蓋，不必分別下載前兩版。它是增量包，保留原資料夾路徑，只含新增或修改的檔案。

## 使用方式

1. 解壓縮到既有網站根目錄，也就是 index.html 所在位置，依原路徑覆蓋。
2. 保留既有牌面、神像、分享卡素材、命理引擎與前次提示詞更新；不要用這份增量包取代整個專案資料夾。
3. 沿用原本的靜態網站發布方式。正式站仍是 HTML 與傳統 JavaScript，不需要改成其他框架。
4. 更新後的樣式與介面腳本版本為 20260911celestial1，Service Worker 快取版本為 v65。

## 本次強化

- 首頁改為大幅月光器物構圖：取消小圖塞在右下角的安排，使用漸隱遮罩銜接背景；手機採完整文字、主視覺與操作按鈕的順序。
- 八個命理入口使用獨立的立體器物意象：塔羅牌、開鑰、四葉草、四柱、雙環、星儀、梅花與籤筒。以金屬邊緣、各自的色光、立體底座感與懸浮回饋統一質感。
- 同一套器物延伸到命理頁標題、塔羅／開鑰方式選擇、八字合盤與延伸工具，重新整理表單、選中狀態、結果重點、複製提示詞區、AI 入口、牌陣選單與分享視窗。
- 蝦皮保留原本賣場網址：頁首、各命理頁與首頁「月光選物」入口自然銜接，不捏造商品庫存、銷量或功效。
- 主要說明文字以 16px 為基準；操作標籤 14px，次要資訊 12px。保留鍵盤焦點、減少動態效果偏好與手機可捲動的命盤。

## 返回鍵與實際修正

| 位置 | 返回行為 |
| --- | --- |
| 頁首品牌、塔羅問題頁 | 返回首頁，保留已寫問題。 |
| 塔羅抽牌／結果頁 | 返回修改問題；另有返回首頁。 |
| 開鑰之法 | 問題頁可返回首頁；原有設定上一步、取消儀式與結果返回仍可使用。 |
| 八字、雷諾曼、梅花 | 表單可返回首頁；結果頂部可返回修改，另提供首頁入口。 |
| 紫微結果 | 返回修改時帶回日期、時辰、性別與問題，也支援「時辰未知」。 |
| 八字合盤與其他八字分頁 | 可返回首頁；單人／合盤／人格結果增加返回修改資料，沿用原分頁及表單草稿。 |
| 靈籤 | 各階段頂部有具文字的返回首頁鍵；儀式與確認規則維持既有程序。 |

修復塔羅表單原本呼叫不存在的 backToHook()；修復紫微結果返回表單會清空資料。各命理頁不再只依靠沒有文字的小箭頭。這裡說明的是畫面上的返回操作，沒有宣稱所有手機系統返回手勢均已驗收。
