# 第一版＋第二版 UI 合併更新包

這一包已合併第一版的整站 Moon Atelier UI，以及第二版的梅花、八字合盤、靈籤與操作說明修正。預覽頁和實測紀錄也包含在內。

# 靜月之光 · Moon Atelier 介面更新

版本：20260911atelier2。這是接續前次命理提示詞、分享卡與預覽修正的增量更新，壓縮檔只含本次新增或修改的檔案。

將壓縮檔解開至既有專案的根目錄（有 index.html 的位置），依原路徑覆蓋，再沿用原本的靜態網站發布方式。不要以這個增量包取代整個專案資料夾；原有牌面、神像、字體、排盤引擎及前次更新仍需保留。

package.json / package-lock.json / vite.config.mjs 提供開發預覽與測試指令。正式站仍使用原來的 HTML 與傳統 JavaScript，不需要遷移框架或改成 Vite 打包站。

## 本輪實際操作後的修正

- 梅花結果：顯示原問題與體／用卦名；以「體用初判」說明助力、消耗、制約，配合旺衰、互卦、變卦閱讀，避免單一「大吉／凶」被誤當整體結論。變卦標示為「後續趨勢」。
- 八字合盤：說清楚關係組數不等於配對分數，各組影響並不等重；結果末尾交代如何複製、送往 AI、對照經驗及整理行動。
- 靈籤：實測發現停止條件是本輪累計三次笑筊／陰筊，修正原本「連續三次」的文字。將「聖杯」改為「聖筊」，實際重抽籤的按鈕改稱「重新搖籤」，並移除未核實的古例引言。計數與求籤規則不變。
- 步驟說明：梅花顯示起卦，雷諾曼顯示選陣與抽牌，八字與紫微顯示核對資料排盤。

## 設計內容

- 首頁：深夜藍、月光金、立體金屬圖示、既有月亮器物主視覺；八個獨立工具入口，包含直接開啟八字合盤。
- 塔羅：輸入區、分析方式、十四種牌陣選單、讀牌方式、選牌區、提示詞及分享區。選單支援 Escape、循環鍵盤焦點與關閉後返回原按鈕。
- 開鑰之法：代表牌選擇、問題領域設定、五次操作的共用容器與結果面板；原有操作幾何與程序停止規則仍由原引擎決定。
- 雷諾曼：自動選陣說明、三／五張線、雙路比較、九宮格、大牌陣；結果增加實際牌位標記，大牌陣按 8×4＋底部4張呈現，窄螢幕可橫向查看。
- 八字與合盤：四柱、單人、雙人情境、人格、曆法工具、紀錄、日期／時間／城市選擇器與結果表格。
- 紫微：出生資料、十二宮、四化標記、摘要及解讀區；十二宮保留完整位置，在手機可橫向查看，避免把星曜縮成難讀的小字。
- 梅花：時間、數字、漢字三種現行起卦方式、輸入、三卦結果、解讀與分享；切換方法時對文字安全轉義並保留輸入。
- 靈籤：保留既有神像與儀式內容，重新安排神像、問題欄、說明與求籤按鈕，並統一操作及解讀區。
- 全站：字體層次、輸入框、選中狀態、焦點、按鈕、分享視窗、頁尾與蝦皮水晶選物入口。新版停用全螢幕墨流背景，讓內容與表單更穩定。
