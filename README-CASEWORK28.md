# 處境判讀與問意傳遞修正 · 20261016case28

這是變動檔案包，解壓後把 `mytool-blue-master` 內的檔案覆蓋到既有專案相同路徑。不是完整網站，沒有刪檔，也沒有重新抽牌或補造出生資料。

## 本次修正

- 共用問意流程辨認出勤取捨、已完成的行動、情緒與長期方向；分開本人承受、外在責任、支援及後果。學校請假、上班遇到異性的反例不強套現場排班。
- 十五種方法各自保留原生取法，新增對應的處境閱讀指引；這些是解讀任務，不冒稱新算出的事件。照顧、合作退出等問題也有交接與責任核對入口。
- 六壬的工作取用不再因「上班、請假」漏詞而落入 unresolved-topic。本人與事情環境分讀，分類問事資料會送進一次貼上的正文。
- 六壬伏吟按有克／無克及自刑、互刑分支標示；本題為有克，不能標成無克自信。原典杜傳例另分。補上丑刑戌、戌刑未、未刑丑等有向關係，五行比和與刑沖可並存。
- 課體成立與未決的版本條件保留在必要資料內；不因加入處境文字就刪掉三奇等相反依據。修正缺行年卻連帶誤報缺月建的情況。
- 六爻補充背景後重新辨認取用與作用網，保留原爻、日期、手動取用及明示期限；輸出使用重新分析後的資料。同一爻的相同旺衰只列一次，伏神或不同狀態仍另列。
- 舊六壬紀錄只在三傳一致時更新取法標籤；不一致則要求覆核原輸入，不偷偷改盤。
- 提示詞改為直接對本人說話、先回答眼前的事，減少報告語與自我解說；保留必要條件，不假扮真人。手鍊段改為自然短段，仍不宣稱療效或改運。
- 審稿新增外在工作處境漏答、未提供人數、事後回報冒稱事前命中與報告式開頭檢查。假設、問句、傳聞、否定與本人回報分開。這是文字檢查，不能保證所有模型都遵守。
- 同步既有內嵌流程、單次貼上執行碼與可證明同源的根目錄鏡像；快取版本更新。

## 本題應看見什麼

原始問題與盤面可以引導解讀者比較「自身消耗」及「外在職責牽制」，並核問替補、交接和主管調度是否到位。不能只講心情、目標或勸努力。

「今天已有四人請假，自己再請假會讓現場無法運作」是使用者後續回報，不能從原盤唯一推出。本次沒有把這句答案寫死進正式引擎；它只出現在回歸測試與測試輸出。也沒有用資料量多、計算通過或多方法一致來保證看透未知事實。

本題未提供本命與長期運限，短期占問不能替它指定人生翻轉日期。可以回答當下走向與觀察條件，不能編造何年何月必然重獲目標。
